## Два порядка (не путать)

**Список вслух (2026-08-16)** — как называли этапы:

```
lab ✅ → Draco skip → MCP last
→ MVPainter (tex) → RVG (реальные 2–4 фото) → Hi3DGen последним
❌ img2mv
```

**Почему я открыл Hi3DGen раньше пунктов 4–5:** не отмена списка, а **гейт**.  
MVPainter в спайке W3: не стартовать, пока W3a polish PASS (High≈Realistic).  
RVG: не жечь без реальных 2–4 фото / слотов.  
Hi3DGen в `t2FinishPlan`: открывать **после** «T2 сдали» — форма+tex в worker уже freeze.

Итого: вслух Hi3DGen **последний**; «сейчас» = первый **разблокированный** пункт из ▲ (сети), пока 4 и 5 стоят на гейтах.

**Апдейт 2026-08-20:** H0 отработан и закрыт → из очереди ▲ Hi3DGen **выпадает**. Остались MVPainter (гейт: W3a polish PASS) и RVG (гейт: реальные 2–4 фото). Оба гейта на месте, поэтому следующий шаг выбираем сознательно, а не «по остатку».

**Апдейт 2026-08-21:** Pixal3D и Direct3D-S2 закрыты как quality. Парк Ф2 next = **Step1X-3D** (geometry first). TokenRig/анимация — Ф6, не вместо ширины img2mesh.

## H0 — 🟡 ПЕРЕСТАВЛЕН 2026-08-20 (качество нет, быстрый тир да)

Дырка продукта была: **львы / табард мыло в меше**. H0 её не закрывает.

Hi3DGen = файнтюн **TRELLIS v1** + normal bridge (MIT), выход — геометрия без PBR.  
Наш T2 = **TRELLIS.2-4B**, следующее поколение той же линейки. Бумага (03.2025) сравнивает себя с **Trellis-RGB / Hunyuan / Dora**, т.е. с v1 — отсюда миф «круче Trellis2».

Проверено 2026-08-20: тот же bust-кроп на **официальном HF Space** дефолтами → 407k verts, **то же мыло**, что у нас (408k YOSO / NiRNE). Более свежего меш-чекпойнта у Stable-X нет; авторы ушли в **ReconViaGen** (`trellis-vggt-v0-2` — у нас уже стоит).

Рычага-каскада, которым разогнали T2 (`pipeline_type 1024/1536_cascade`), здесь не существует: extract фиксированный 256³, 512 ≈ 520 GB VRAM.

Внешняя проверка (`netParkResearch2026.md`): в 3D Arena (123k голосов) Hi3DGen **11-й из 19**, Elo 1207 — ниже TRELLIS v1. Абляция Direct3D-S2 публикует, что 256³ = «limited geometric details», и Hi3DGen сидит ровно там. Миф «лучший» тянется из его же user study против бейзлайнов 2024 года и туториала SECourses.

**Вывод:** как качество — не default и не апгрейд над T2. Но **не выбрасываем**: 8.5 с на голую геометрию (против 167 с у T2) = готовый **быстрый тир**, воркер уже развёрнут. Возврат к качеству — по условиям в `netParkProgram.md` шаг 6 (новый чекпойнт или непроверенный класс входа: реальное фото / камень при 1024 px).

Мастер спайка: `scripts/hi3dgen_h0_spike.md` § Вердикт H0 + Внешняя проверка.

## Очередь после H0 (план 2026-08-20)

Решили гнать все три оставшихся варианта, но по порядку «дешёвое и вероятное → дорогое и рискованное». Один трек за раз, GPU только по кнопке.

Важное следствие закрытия H0: в `mvpainter_w3_spike.md` строка «львы не скульптура — это **Hi3DGen**, не paint» больше не действует. Надежда на микро-геометрию через Hi3DGen умерла, значит единственный оставшийся путь к скульптурным львам — **поднять эффективное разрешение у T2**. Отсюда N1.

### N1 — T2 `1536_cascade` на bust-кропе (первый, дешёвый)

Гипотеза: единственный рычаг, который в H0 реально дал прирост, — это кроп (7.4 → 21 МБ на том же входе). Мы применяли его к сети с фиксированным extract 256³. У T2 разрешение крутится до 1536, а кроп на T2 мы **ни разу не пробовали** — всегда кормили полноростового рыцаря.

| | |
|--|--|
| Вход | `preview_textures/ref_gold_armor_bust.png` → в R2 через лаб (`studio_lab.ps1`, файл→R2) |
| Прогон | `python test_req_trellis2.py --image-url "<r2>" --quality-tier ultra --pipeline-type 1536_cascade --texture-mode textured --texture-size 4096 --seed 1 --save preview_textures/t2_bust_ultra.glb` |
| Baseline | `armor_t2_v17_realistic.png.glb` (полный рост, тот же tier) |
| Глаза | лев на груди и кромки палд вблизи, каркас + albedo off. Сравнивать **тот же участок**, не общий силуэт |
| **PASS** | лев читается как рельеф, а не волна → кроп становится частью prod-рецепта для крупного плана |
| **FAIL** | та же волна → потолок микро-геометрии подтверждён для всего класса TRELLIS, микро уходит в текстуру/нормаль-мапу навсегда |
| Стоп | не крутить seed’ы и не гонять полный рост «для сравнения» — baseline уже есть |

### N2 — RVG `trellis-vggt-v0-2` на реальных ракурсах (гейт на юзере)

Гейт настоящий: RVG — это фьюжн **реальных** фото, не img2mv. Наш рыцарь — CGI-реф, реальных ракурсов у него не существует, поэтому прогон на нём смысла не имеет.

| | |
|--|--|
| Что нужно от юзера | 3–4 фото **одного физического предмета** телефоном: фронт / бок / зад (+ 3/4), один свет, предмет не двигали |
| Прогон | `worker_reconviagen.py` (эндпоинт) либо `scripts/reconviagen_hf_smoke.py --image a.png --image b.png --save out.glb` |
| Побочный A/B бесплатно | тот же набор в T2: `test_req_trellis2.py --image-urls a b c --multi-image-mode multidiffusion`. Это отвечает на «нужен ли RVG вообще» |
| **PASS** | зад/бок цельные без домыслов сети → это и есть путь A `productMultiUx.md` (слоты реальных видов) |
| **FAIL** | RVG не лучше T2-фьюжна → слоты делаем на T2, RVG закрываем |
| Стоп | синтетику в RVG **не кормить** (класс img2mv FROZEN) |

### N3 — MVPainter W3b (последний, дорогой)

Формально был закрыт как «не next» после W3a PASS. Открываем только потому, что решили пройти все варианты, и только после N1/N2.

| | |
|--|--|
| Цена | ≥40 GB VRAM → dedicated **A6000 48GB** (в 4090-пуле нет), установка Blender + растеризатор 1–2 ч |
| Вход | нативный T2 GLB, `--geo_rotation -90` |
| Смысл | learned delight вместо CPU-фейка W3a; tangent normal map MVPainter **не обещает** |
| **PASS** | львы/табард убедительнее `armor_t2_ultra_native_pbr_delight.glb` |
| **FAIL / abort** | OOM на 669k, виды разъехались, или не лучше W3a → **terminate pod в той же сессии**, не decimate «чтобы влезло» |

### Порядок и стоимость

1. **N1** — сегодня, наш serverless живой, один джоб. Отвечает на главный вопрос продукта.
2. **N2** — как только юзер снимет 3–4 фото. Бонусом даёт T2-фьюжн A/B бесплатно.
3. **N3** — только после первых двух, с готовым abort-критерием.

Не смешивать в один вечер: каждый пункт даёт вердикт глазами, а вердикты нужны раздельно.
